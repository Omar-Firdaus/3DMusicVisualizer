3D Music Visualizer

Explanation of why I'm building the project:

Over the past few months I've been getting more and more into music production. A lot of this production is done in software that's not very good at visualizing the experience of listenting to music. Because of that, I wanted to create a visual experience that goes beyond the waveforms in Logic Pro, and creates some sort of visually stunning experience. I also want to take advantage of the opportunity to showcase the music I'm working on, so for the project I'm going to be building at least 1 entire new song. Because the visuals are about my new music, I also want to make it something that demonstrates the goal of my music's design.

Criteria:

There's a couple things I want in this project, but here are some of the negotiables that I really want on the site:

- Entire site is dedicated towards the music's design philosophy. As cliche as it sounds, I want the visualization and surrounding enviornment to be built to the music I'm producing and no one elses. I think designing and themes specifally accustomed to the tracks I'm making will immerse whoever is using the site, better than any other visualzier.

- The visualization needs to be 3D. I feel like being in an enviornment in 3D, immerses users far greater than a boring 2D waveform that you see a lot. I'll update how this is going to be done as I go deeper into the project, but it's likely going to be based around some sort of Three.js.

- Avoid using off the shelf tracks and visuals. This one is self expalantory, build form the ground up.

- Give the user the opportuntiy to tinker with the track's eq, fx, and whatever else I think might be a good fit for the visualizer. This is going to be done through fader knobs of some sort, so I can replciate that feeling of physical hardware.

- Also a feedback form. Being able to take advice staright from the site would be pretty sweet.

Usage:

Just go to the link to start the project. Pause, play, and loop controls are pretty self explanatory. Expiriment with adding and adjusting EQ & FX, along with muting or increasign the volume of certain tracks.
